# 시드 데이터

데모와 매칭 정확도(Top-3) 측정용 데이터입니다. DB에 직접 넣지 않고 **등록 API와 같은 로직으로** 넣어서
AI 사진 분석·설명문·임베딩·매칭이 실제로 실행되게 합니다.

```
seed/
├── seed_items.csv      # 실제 시드 데이터 (습득물 35건, 분실물 11건, 정답 쌍 11개)
├── seed_template.csv   # 새로 만들 때 쓰는 빈 템플릿
└── photos/             # 사진 파일 (git에 올리지 않음, 팀 드라이브로 공유)
```

## 넣는 방법

```bash
python manage.py migrate          # 장소(places 0002) 포함
python manage.py seed_demo        # 등록 → 매칭 → Top-1/Top-3 정확도 출력
python manage.py seed_demo --reset   # 시드 계정 데이터를 지우고 다시 넣기
```

- `.env`에 `OPENAI_API_KEY`가 있어야 합니다. 사진 수만큼 AI를 호출해서 몇 분 걸립니다.
- 시드 계정: 분실자 `demo.owner@jejari.ac.kr`, 습득자 `demo.finder1~3@jejari.ac.kr`
- 시간 칸은 `-2 14:00`(2일 전 14:00)처럼 상대 시간으로 써서, 언제 넣어도 최근 등록으로 보입니다.
- **시연 메인 시나리오(검정 무선 이어폰)는 분실물을 시드에 넣지 않았습니다.** 시연 때 분실자 계정으로
  "검정색 무선 이어폰, 중앙도서관 2층, 어제"를 직접 등록하면 이어폰 습득물 3건이 후보로 나옵니다.

## 행 하나 = 등록 1건

| 컬럼 | 습득(found) | 분실(lost) | 설명 |
|---|---|---|---|
| `row_type` | `found` | `lost` | |
| `pair_id` | 정답 쌍 번호 | 같은 번호 | 같은 물건인 습득·분실 행에 같은 번호 (예: `1`). 짝이 없는 행은 비움 |
| `photo_file` | **필수** | 선택 | `photos/` 안의 파일 이름 (jpg, png) |
| `source_url` | 권장 | 권장 | 사진 출처 (발표 자료 출처 표기용) |
| `category` | 비우면 AI 분석값 | **필수** | 물건 종류 목록 중 하나 (아래 참고) |
| `item_name` | 비우면 AI 분석값 | **필수** | 예: `검은색 가죽 반지갑` |
| `color`, `brand` | 비우면 AI 분석값 | 선택 | |
| `features` | 비우면 AI 분석값 | 선택 | 외형 특징, `;`로 구분 (예: `가죽;모서리 해짐`) |
| `description` | 선택 | 사진 없으면 **필수** | 상세 설명 |
| `place` | **필수** | **필수** | 건물 이름 (Place에 등록된 이름과 똑같이) |
| `location_detail` | 선택 | 선택 | 층·강의실 |
| `time_from` | **습득 시각** | **분실 추정 시작** | `2026-11-20 15:20` 형식 (한국 시간) |
| `time_to` | 비움 | 분실 추정 끝 | 비우면 `time_from`과 같음 |
| `storage_status` | **필수** | 비움 | `SELF` 직접 보관 / `HANDED_OVER` 인계 |
| `storage_location` | 인계면 필수 | 비움 | 예: `중앙도서관 1층 안내데스크` |
| `private_features` | 강력 권장 | 비움 | 사진에 안 보이는, 주인만 아는 특징 → 소유권 확인 질문에 사용 |
| `memo` | | | 메모 (등록에 안 씀) |

- `pair_id`가 `EX`로 시작하는 예시 행은 등록하지 않습니다. 확인 후 지워도 됩니다.
- 습득물 시각은 분실 추정 시작 시각보다 **뒤**여야 매칭 대상이 됩니다.

## 물건 종류 (category)

`지갑`, `카드·신분증`, `휴대폰`, `이어폰`, `전자기기`, `가방`, `우산`, `텀블러·물병`, `의류`, `액세서리`, `열쇠`, `책·문구`, `기타`

## 구성 가이드

- 정답 쌍 **약 20개** + 짝 없는 행 **10~15개**
- 실제로 많이 잃어버리는 종류(지갑, 이어폰, 카드·신분증, 우산, 텀블러)는 2~3쌍씩, 나머지는 0~1쌍
- **같은 종류의 비슷한 물건을 일부러 섞기** (예: 검은 지갑 3개 중 정답 1개) — 매칭이 진짜 짝을 고르는지 보는 핵심
- 분실 행은 습득 사진을 보고 주인이 쓸 법한 말로, **표현을 다르게** (예: 네이비 카드지갑 ↔ 남색 지갑)
- 일부 쌍은 장소를 옆 건물로, 시간을 몇 시간 뒤로 다르게
- 분실물 사진 등록(C-02)도 보여 주려면 분실 행 몇 개에 다른 각도·다른 사진을 넣기

## 사진 주의

- Unsplash, Pexels, Pixabay 같은 무료 라이선스 사진만 사용, 쇼핑몰·블로그 사진은 사용 금지
- 실제 학생증·신분증·카드, 사람 얼굴이 나온 사진은 사용 금지 (블러 시연은 직접 만든 가짜 학생증으로)
- 하얀 배경 상품 사진보다 책상·바닥에 놓인 "주운 듯한" 사진이 좋음
